# FanZone

FanZone is a stadium food ordering mobile application developed using **Flutter** and **Firebase**, designed to enhance the match-day experience by allowing fans to order food directly from their seats.

## Features

* QR-based seat ordering
* Real-time order tracking
* Stadium map and navigation
* Product and menu browsing
* Inventory management
* Push notifications
* Admin management system

## Technologies

* Flutter
* Dart
* Firebase
* Firestore
* REST API
